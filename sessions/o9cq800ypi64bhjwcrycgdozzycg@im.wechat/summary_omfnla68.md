## 任务背景
用户想把心学内容（知行合一）保存到有道云笔记，但遇到 401 认证失败问题。

## 执行过程
1. 检测到 API Key 已配置但返回 401
2. 引导用户在 QClaw 应用内重新授权
3. 用户确认已重新连接，但测试仍失败
4. 检查 get-token.sh 返回旧 token，确认授权已过期

## 关键结果
- 有道云笔记 API 授权已失效，需要用户手动获取新 API Key
- 用户需访问 https://mopen.163.com 登录并生成新 API Key
- 心学内容保存任务暂挂，等待新 API Key
