# Task Artifact: 查理·芒格每日三条语录生成

## Objective
创建一个定时任务，每天下午13:00从查理·芒格的100条核心语录库中随机选取3条语录，使用日期作为随机种子确保每天的选择固定不变。

## Key Reasoning
1. **语录库创建**：工作区中原本没有芒格语录库，需要先创建一个包含100条核心语录的Markdown文件，涵盖10个类别（投资基础、思维模型、逆向思维、误判心理、决策框架、人生智慧、商业洞察、风险意识、价值投资、心智模式），每个类别10条语录。

2. **随机种子设计**：使用日期（YYYYMMDD格式）作为随机种子，确保同一日期总是选择相同的3条语录，不同日期会选择不同的语录。今天（2026-05-24）的种子是20260524。

3. **Python实现**：使用Python的`random.seed()`设置随机种子，然后用`random.sample()`从100条语录中选择3条不同的语录。

4. **输出格式**：严格按照用户要求的格式输出：【查理·芒格今日三条·第3次】+ 3条语录（每条带类别标签）。
